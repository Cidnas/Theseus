# Changelog

## Unreleased

Initial development of Theseus, a Python library for embedding the Codex
app-server in applications.

- Agent handles, structured results, streaming, and model/effort configuration.
- Dynamic sync/async Python tools with JSON Schema validation and per-agent
  capability selection.
- Skills, explicit external integrations, and isolated project state.
- Resumable threads, concurrent agents, cancellation, deadlines, and bounded
  tool execution.
- Deterministic protocol tests, opt-in live integration tests, and a local
  transport benchmark.

- Usage-focused documentation with examples for tools and concurrent agents.
